 ║  肆、檔案說明  (￣▽￣)ノ             ║
 ╚══════════════════════════════════════╝

  真正在跑的只有這三個：

    index.html          ← 主頁
    styles-music.css    ← 外觀
    script-music.js     ← 會動的部分＋音樂


 ╔══════════════════════════════════════╗
 ║  伍、要上傳到網路的話  (ง •̀_•́)ง      ║
 ╚══════════════════════════════════════╝

  images/ 跟 media/ 一定要跟 index.html 放在同一層！
  資料夾長這樣就對了：

    你的網站/
    ├── index.html
    ├── styles-music.css
    ├── script-music.js
    ├── images/      ← 相冊照片
    └── media/       ← GIF 廣告＋音樂

  少一個資料夾 = 圖片破圖 = 站長哭哭 (╥﹏╥)
